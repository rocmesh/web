LilyGO T-Deck Plus

A BlackBerry-style handheld with a full keyboard, trackball, color screen and GPS. Send and read messages right on the device, no phone needed.

MeshCore Meshtastic Standalone Keyboard GPS ~$81-87

What it is

The T-Deck Plus is a pocket-sized handheld from LilyGO that looks like an old BlackBerry. It has a backlit QWERTY keyboard, a trackball and a 2.8" color screen, with an ESP32-S3 chip and a Semtech SX1262 LoRa radio inside. Both Meshtastic and MeshCore have on-screen interfaces for it, so you can read and type messages without pairing a phone.

The Plus adds built-in GPS and a 2000 mAh battery to the original T-Deck, so it's ready to carry out of the box. We keep ours in a 3D-printed stand on the desk, where it doubles as a message display.

ProcessorESP32-S3 (Wi-Fi and Bluetooth LE 5.0), plus an ESP32-C3 that runs the keyboard
RadioSemtech SX1262 LoRa, 915 MHz version for the US
Screen2.8" IPS color screen, 320 x 240 (not a touchscreen)
KeyboardBacklit QWERTY keyboard and trackball (Alt + B toggles the backlight)
GPSBuilt in. It uses the Grove port, so that port isn't available for other add-ons
AntennaExternal, on an IPEX (u.FL) connector
AudioSpeaker and microphone
Battery2000 mAh, charges over USB-C, with a power switch on the side
DocumentationMeshtastic docs, LilyGO on GitHub
FirmwareMeshCore, Meshtastic (with its on-screen interface)

Role in the mesh

Recommended

Standalone messenger

What it does best. The full keyboard and big screen make it the most comfortable way to message without a phone, whether it's in your hand or sitting on a desk.

Works

Phone companion

It pairs with your phone like any other node, but you'd be carrying a keyboard and screen you don't need. For a smaller companion, see the T1000-E or Heltec T114.

Not recommended

Repeater

It can relay, but the big screen and ESP32 use a lot of power, and the keyboard goes to waste. For a fixed site, use the RAK 1W Repeater.

Where to buy and what it costs

Choose the 915 MHz version for use in the US, and make sure the listing says T-Deck Plus. The original T-Deck looks the same but has no GPS.

Setup

Attach the antenna before you power it on or flash it. Then flash the firmware from a web browser (Chrome or Edge) with the T-Deck Plus plugged in over USB-C, and pick T-Deck from the flasher's device list (the Plus uses the same firmware). For Meshtastic, enable the on-screen interface (Meshtastic UI) when flashing.

If the flasher can't find it: turn the power switch off, hold down the trackball, turn the power switch on, then let go after 2-3 seconds. A black screen with the backlight off means it's ready to flash.

  • MeshCore: MeshCore web flasher, then see MeshCore companion settings.
  • Meshtastic: Meshtastic web flasher, then see Meshtastic companion settings.
