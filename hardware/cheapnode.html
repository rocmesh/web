Budget Heltec V3 Node

A Heltec V3, a GPS module and a $2 craft-store box. Proof that getting on the mesh doesn't take much money or skill.

MeshCore Meshtastic Companion GPS ~$33

What it is

This is the simplest mesh node we could build. It's a Heltec V3 with its antenna, plus a GT-U7 GPS module, tucked into a clear plastic crayon box from Michaels. It runs from any USB power bank, so there's no battery wiring at all.

It's not pretty, but it works. That's the point: if you can connect four wires and plug in a USB cable, you can build a mesh node for about $33.

Role in the mesh

Recommended

First build

What it's for. It's cheap, quick, and needs almost no tools, so it's a great way to learn how a node goes together before you build something fancier.

Recommended

Home base companion

Plug it into a phone charger by a window and leave it on. The screen shows new messages, and you can connect from your phone or computer.

Not recommended

Outdoor repeater

It'll relay indoors, but a crayon box won't survive the weather, and the ESP32 drains a power bank quickly. For a fixed outdoor site, use the RAK 1W Repeater.

Where to buy and what it costs

There's no kit for this one. Everything comes from the parts list below. Make sure the Heltec V3 is the 915 MHz version, and bring your own USB power bank.

The build

The Heltec V3 and GPS module sit loose in the crayon box, with the antenna poking out the top and a USB cable running out the side. There's no case to print and only four wires to connect.

Assembly notes

  1. Flash the firmware first (see Setup below).
  2. Screw the antenna onto the Heltec V3. Never power the radio without an antenna attached.
  3. Wire the GT-U7 to the Heltec V3 (from the Meshtastic GPS guide):
    • GPS TXD to V3 GPIO 48
    • GPS RXD to V3 GPIO 47
    • GPS VCC to the V3's 3V/5V pin
    • GPS GND to the V3's GND
  4. In the Meshtastic app, go to Radio Configuration > Position and set GPS RX pin to 48 and GPS TX pin to 47. If the app says "No GPS present", double-check those two wires and settings. If it says "No GPS lock", move the node somewhere with a view of the sky.
  5. Optional: the GPS uses a lot of power. The Meshtastic guide shows how to add a small MOSFET (such as a 2N7000) on GPIO 46 so the firmware can switch the GPS off. Then set the GPS enable pin to 46, and press the V3's user button three times to turn the GPS on or off.
  6. Drop everything in the box, run the USB cable out the side, and plug it into your power bank.
