Recommended Companion Settings

Make sure to match these settings in your Meshtastic client app to ensure you can talk to the local mesh!

When setting up your node, select the US region. The crucial requirement is that your Region, Frequency Slot, and Modem Preset match the parameters listed below.

Setting Value Location in App Notes
Region US LoRa Config > Region Sets the 915 MHz band for North America.
Modem Preset LongFast LoRa Config > Modem Preset Default preset (SF11, BW 250 kHz, CR 4/5). Do not change to custom unless requested.
Frequency Slot 20 (906.875 MHz) LoRa Config > Frequency Slot Standard public channel slot index for US operations.
Device Role CLIENT Device Config > Role Standard mobile/portable companion setup. Do NOT select ROUTER or REPEATER.
Hop Limit 3 LoRa Config > Hop Limit Default max hops. Prevents mesh airtime congestion while maintaining coverage.
Position Precision Approximate / 100m Position Config > Location Precision Preserves battery, saves airtime, and protects privacy on public channels.
