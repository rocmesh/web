Recommended Infrastructure Settings

These settings represent the current ROCMesh standards for local Meshtastic infrastructure nodes. Please ensure any home base station or repeater node you manage is configured to match the recommendations on this page.

Radio & Network Settings

Infrastructure node settings are critical because fixed relays support the broader local mesh. Unlike standard handheld client nodes, infrastructure devices require carefully selected roles, power management, and broadcast rates to avoid saturating local RF airtime.

Setting Value Location in App / CLI Notes
Region US LoRa Config > Region Sets the 915 MHz ISM frequency band.
Modem Preset LongFast LoRa Config > Modem Preset Standard public preset (SF11, BW 250 kHz, CR 4/5).
Frequency Slot 20 (906.875 MHz) LoRa Config > Frequency Slot Standard US public channel index.
Hop Limit 3 LoRa Config > Hop Limit Prevents packet loops while supporting multi-hop links across the region.
Device Role CLIENT_BASE Device Config > Role Recommended standard for home base stations, attic nodes, and local repeaters.

Infrastructure Roles Explained

Meshtastic uses specific roles to dictate how aggressively a device forwards traffic and whether it appears on public node lists. Selecting the correct role for your installation prevents channel congestion and optimizes local performance.

Role Visible on Mesh Map? Best Use Case
CLIENT_BASE Yes Recommended Standard: Acts as a standard client relay for the general public mesh, but uses priority rebroadcast timing for any favorited nodes (such as your handhelds or indoor devices). Perfect for home base stations, attic mounts, and rooftop relays.
CLIENT Yes Standard Relay: Ideal for mobile setups or general node installations. Intelligently rebroadcasts packets across the mesh using standard contention timing.
ROUTER_LATE Yes Fill-in / Dead-spot Relays: Waits until standard clients finish rebroadcasting before transmitting. Useful for valley locations or shadowed urban clusters.
REPEATER No Silent Infrastructure: Relays packets with minimal overhead and zero telemetry broadcasts. Does not appear on local node lists or client maps. Avoid unless operating dedicated solar infrastructure with no local user nodes.
How to take advantage of CLIENT_BASE:

Once your repeater is set to CLIENT_BASE, open the Meshtastic app on your handheld or indoor node, locate your repeater in the Nodes list, and tap the Favorite (Star) icon. Do the same on your repeater node to favorite your handheld. This tells the repeater to fast-track messages sent to and from your personal devices through its well-positioned antenna!

Broadcast & NodeInfo Intervals

Infrastructure nodes send periodic status packets to help local client nodes map out topology. Increasing these intervals reduces airtime usage on high-traffic channels.

Broadcast Type Recommended Interval CLI Parameter
NodeInfo Broadcast 10,800 sec (3 hours) device.node_info_broadcast_secs = 10800
Telemetry Broadcast 7,200 sec (2 hours) or Disabled telemetry.environment_update_interval = 7200
Position Broadcast 10,800 sec (3 hours) or Fixed position.position_broadcast_secs = 10800

Location & GPS Guidance

It is strongly recommended to set a Fixed Position on permanent infrastructure nodes so local users can discover nodes on regional mesh maps. Because infrastructure nodes are stationary, always disable hardware GPS and manually enter your coordinates via the app or CLI. Disabling onboard GPS hardware saves significant battery/solar power and prevents unnecessary position drift packets over the air.

CLI Configuration (Meshtastic Python CLI / Serial)

You can configure your repeater node via serial using the standard meshtastic Python CLI tool or the built-in Web Serial Console. Run the following commands in sequence: 

# Set basic region and modem defaults
      meshtastic --set lora.region US
      meshtastic --set lora.modem_preset LONG_FAST
      meshtastic --set lora.hop_limit 3

      # Set infrastructure role to CLIENT_BASE
      meshtastic --set device.role CLIENT_BASE

      # Throttle routine presence broadcasts to preserve channel airtime
      meshtastic --set device.node_info_broadcast_secs 10800
      meshtastic --set position.position_broadcast_secs 10800

      # Set a fixed location (replace with your lat, lon, and altitude in meters)
      meshtastic --set-owner "ROC-Rpt-North"
      meshtastic --set-lat 43.1566 --set-lon -77.6088 --set-alt 150
      meshtastic --set position.fixed_position true

      # Disable onboard GPS hardware to save power
      meshtastic --set position.gps_mode DISABLED

      # Reboot the node to apply all configuration changes
      meshtastic --reboot
