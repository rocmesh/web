Recommended Repeater Settings

These settings represent the current ROCMesh standards. Please ensure any repeater you manage is updated to match the settings on this page.

Radio/Network Settings

Repeater settings are more important than companion settings because your repeater is infrastructure and will be used by other members of the mesh. These tables summarize recommended settings, with easy copy-pastable commands to configure your companion at the bottom of the page.

Setting Value
Preset USA/Canada OR Custom
Frequency (MHz) 910.525
Bandwidth 62.5 kHz
Spreading Factor 7
Coding Rate 8
Enable Repeat Mode Unchecked
Default Path Hash Size 2-byte

Regions

Region-scoped packets will not get repeated by your repeater unless the repeater is configured to do so. Regions are starting to get more use in our area, so it's important to make sure our repeaters can properly support them.

Region Description
na North America
us United States
east Eastern United States
northeast Northeastern United States
us-ny New York State
roc Rochester area (not just the City)
onny Ontario, Canada and New York State

Advert Intervals

Repeater adverts help companions and other repeaters discover your repeater. The default settings are okay, but these will help more users discover the mesh without creating too much unnecessary traffic.

Advert Type Interval
Flood 3 hours
Zero-hop 60 minutes (or 0 minutes if you have lots of repeaters nearby, which will disable direct adverts)

Location

It is recommended to set your repeater's location so that others can discover it on the map! You don't have to use your exact location (but you can, and many people do); neighborhood-level accuracy is usually fine. If you do choose to set your repeater's location, do so using the map, not with GPS. GPS is unnecessary on a repeater since it doesn't move, and will only drain the battery faster.

Additional Tweaks

Additional tweaks are possible, but must be done with care. Some recommended tweaks which increase mesh stability at the cost of slightly increased latency are included in the CLI section below.

CLI Configuration

The easiest way to configure your repeater is to use its command line. Log into the repeater's CLI (Command Line Interface) and run each of these commands in order. Each line is a separate command. Do not paste the lines starting with "#". These are comments to help you understand what you are doing. 


        # Configure radio settings (frequency, bandwidth, spreading factor, coding rate)
        set radio 910.525,62.5,7,8
        # Set 2-byte path hash
        set path.hash.mode 1
        # Configure advert intervals
        set flood.advert.interval 3
        set advert.interval 60
        # Configure additional settings for improved reliability
        set agc.reset.interval 4
        set multi.acks 1
        set rxdelay 3
        # Reboot to save settings (you will likely have to reconnect to the repeater after this)
        reboot
        # Update the repeater's internal clock
        clock sync
        # Verify all of our settings saved
        get radio
        get path.hash.mode
        get agc.reset.interval
        get multi.acks
        get rxdelay
        get flood.advert.interval
        get advert.interval
        # Set regions
        region def na|* us|* east|* northeast|* us-ny|* roc|* onny
        region save
        # Reboot one more time
        reboot
        # Verify regions saved
        region
        # Finally, send an advert to introduce your repeater to the mesh!
        # Do this once you have installed the repeater in its permanent home (and set its location).
        advert
